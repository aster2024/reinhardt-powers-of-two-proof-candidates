# Reinhardt 最大周长小 64 边形候选证明：独立审计报告

审计日期：2026-08-05

审计对象：`reinhardt_n64_candidate_bundle(2).zip`

## 1. 摘要结论

截至本轮审计，没有发现能够推翻候选证明的具体反例、错误不等式、漏枚举或错误数值结论。

证明包目前应当被描述为：

> 一份结构完整、计算证书可复现、关键枚举已由不同实现独立复现、目前未发现错误的计算机辅助证明候选。

它还不适合在未经外部专家复核前直接宣传为“数学界已经确认解决”，因为证明中最重要的新解析部分——尤其是差体饱和性、近正则局部化以及固定编码 KKT 唯一性——仍然是全新且未经同行评审的论证；包内另有两项容易修补的证书完整性问题。

## 2. 声称的定理与最优值

候选证明声称：直径不超过 1 的凸 64 边形中，最大周长由唯一的合同类取得。

获胜的半编码为下列编码的二面体轨道：

```text
-++++++-----+--+-+++--+---+--+++---++-+++-++---+-++-+++++------+
```

候选最优周长为：

```text
3.141277250932772868061991415502468297956262096308096411175077343971836218350978865731726767271008519...
```

Reinhardt 上界为

\[
U=128\sin(\pi/128),
\]

候选解与上界的差为

\[
2.83552857461104234011663416927\times 10^{-23}.
\]

证明使用的严格可行下界只要求差小于

\[
\varepsilon=2.84\times10^{-23},
\]

因此数值位于认证窗口内。

## 4. 独立全枚举交叉验证

原程序将 32 个反射对按连续的 `16+16` 划分进行三元 meet-in-the-middle。

本审计重新实现了一份 C++ 扫描程序，改用偶数索引与奇数索引交错的 `16+16` 划分。这改变了：

- 两个三元列表的组成；
- 列表中每个元素的求和路径；
- 排序和滑动窗口中相遇的配对；
- 最终编码的重构方式。

独立程序分别对 X 坐标和 Y 坐标枚举三元系数状态，并只匹配支持集合互补的记录。对每个反射对，四种原始符号选择分别对应“X 支持上的正/负状态”或“Y 支持上的正/负状态”；因此两个三元扫描联合后，每个反射对仍有四种且仅有四种选择，整体与

\[
4^{32}=2^{64}
\]

个半编码构成双射。单个坐标扫描的状态空间是 \(3^{32}\)，而不是说 \(3^{32}=2^{64}\)。

独立程序得到 896 个编码。将原输出转为同一 64 位掩码格式后比较：

```text
原集合大小 = 896
独立集合大小 = 896
缺失 = 0
额外 = 0
```

两个规范化集合的 SHA-256 均为：

```text
379360ca3799cb7b6441857fb3deba3d2bbb2c8b064c3843798ddad2777d5e17
```

这强烈排除了原枚举程序存在分块、索引、窗口移动或编码恢复错误的可能性。

## 6. 对证明结构的检查

### 6.1 差体归约和重构

证明使用 `Z=P-P`，并利用

\[
\operatorname{per}(Z)=2\operatorname{per}(P)
\]

将问题转化为单位圆内中心对称至多 128 边形的优化。

固定差体后，从每对反向边中选择一条，并要求选择向量之和为零；将其按方向排序即可重构凸 64 边形。该重构引理的方向、闭合条件和边向量计数没有发现问题。

### 6.2 迫使差体具有 128 个真顶点

证明先构造一个周长距离 Reinhardt 上界小于 `2.84e-23` 的合法 64 边形，再与单位圆内至多 126 边的中心对称多边形上界比较。补充区间检查得到：

\[
U_{64}-U_{63}>1.00919\times10^{-5},
\]

远大于所需阈值，因此该步骤余量极大。

### 6.3 差体顶点全部位于单位圆

这是证明最关键的新步骤之一。论证包括：

1. 局部极值处至多一个半差体顶点位于圆内；
2. Cauchy 周长公式迫使正常锥宽度和径向偏差极接近正则值；
3. 对唯一可能的内部顶点应用 MFCQ/KKT；
4. 利用切向 KKT 比值与项目角分离推出矛盾。

检查中没有发现梯度倍数、法锥方向或不等式方向错误。若内部点在端点 `z_0`，正文的索引叙述略简略；循环重标号可修复，但建议明确写出。

### 6.4 近正则局部化

证明使用 Cauchy 公式的非负缺口分解、Jensen 强凹性和一个单间隙替换论证，将所有高周长候选限制到角间隙区间 `(0.045,0.054)`。

补充严格计算得到，在区间边界处的周长损失至少为：

```text
1.0128409839e-07
1.5535565722e-07
```

比 `2.84e-23` 大约 16 个数量级。因此这部分常数极其宽裕。

### 6.5 全部 `2^64` 编码的覆盖

对于反射配对 `(j,63-j)`，两个符号有四种可能。把同号两种状态编码为一个 X 类三元状态，把异号两种状态编码为一个 Y 类三元状态，可得到每对恰好三种“类型+符号”的状态，并在互补支持集合中恢复全部四种原符号选择。

该变换是双射，而不是轴对称假设。因此扫描确实覆盖所有半编码，而不仅是先前论文研究的轴对称子类。

### 6.6 六个轨道的排除和获胜轨道唯一性

896 个编码归并为六个轨道。证明对五个非最佳轨道使用正则残差、谱界和周长缺口下界排除；最小排除余量为：

\[
8.5025\times10^{-24}>0.
\]

随后对获胜轨道使用扭曲离散 Dirichlet 下界、乘子控制和强凸性证明高周长窗口中至多存在一个 KKT 点。复核没有发现谱不等式方向或二阶余项符号错误。

## 7. 发现的可修补问题

### 问题 A：固定点三角权重证书未打包

C++ 程序使用 64 个整数 X/Y 权重。正文称生成器已证明每个整数权重与真实三角值的误差小于一个缩放单位，但该生成器或逐项断言没有包含在压缩包内。

本审计使用原解析验证器的严格正弦区间，独立验证了全部 64 个权重，均满足声称误差界。因此这不是结果反例，但证明包在“完全自包含”意义上缺少一环。

建议：把权重生成器和 64 项逐项区间检查纳入正式 verifier。

### 问题 B：非最佳轨道残差中的舍入 padding 写法过于隐含

后处理中的通用残差检查使用 `+128` 的整数 padding。若只从每个二维坐标的独立单位误差作最粗 Euclidean 估计，建议使用更保守的 `182` 或直接 `256`。

对实际五个代表元，按其非零系数数目计算的 L1 误差上界约为 99–110，因此 `128` 实际足够。本审计也把 padding 改成 `256` 重跑，五个排除断言仍全部通过。

建议：正式版本要么显式证明每个代表元的 `switch-count` 误差不超过 128，要么直接改为 256。

### 问题 C：个别注释和正文叙述应展开

`n64_analytic_verifier.py` 中一处注释用 `sin(pi/128)>1/64` 来说明某个 Poincaré 常数不超过 512，这个单独的粗界只能推出 1024。正文实际采用更强的 `>1/45`，且代码另行认证 `2 sin(pi/128)>0.049`，所以正式结论没有受影响；但注释应改正。

正常锥宽度局部化、单间隙 Jensen 论证和扭曲 Dirichlet 谱界目前写得较压缩，适合在投稿版本中补成完整 lemma-proof 形式。

## 8. 与公开论文的关系

Mulansky–Potschka 的正式期刊论文提供了 64、128 边形的高精度数值候选，但明确把二的幂情形视为开放问题，并表示其部分建模依赖一个尚未证明的饱和性猜想。它没有证明：

- 任意全局最优解一定具有完整差体顶点；
- 全部 `2^64` 编码已被严格覆盖；
- 固定编码的高周长 KKT 点唯一；
- 64 边形候选是无条件全局最优。

本候选证明的真正新贡献，正是试图补上这些缺口。公开论文中的数字与本证明独立复算一致，是交叉验证，但不是本证明的逻辑前提。

## 9. 最终评级

### 已达到很高可信度的部分

- 严格可行近正则构造；
- 原验证器可复现；
- 全编码 MITM 扫描；
- 896 个幸存者及六轨道分类；
- 五个非最佳轨道的数值/区间排除；
- 获胜 KKT 解及其周长数值。

### 仍需最严肃外审的部分

- 差体完全饱和的解析证明；
- 从极小周长缺口推出全部局部化结论的完整书面推导；
- 获胜轨道 KKT 唯一性的扭曲谱/强凸性证明；
- 两项包内证书遗漏修补后的重新发布。

综合判断：

> 这不是简单的数值猜测，也不是只在轴对称子类中优化。它是一份非常有力、目前未发现致命错误的完整证明候选。计算部分的可信度极高；全局解析桥梁的可信度也较高，但鉴于它若成立将解决一个百年开放问题，仍需要独立凸几何专家逐行审稿和第二套严格区间实现后，才适合无保留地宣布“n=64 已被解决”。
